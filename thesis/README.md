# Thesis source

This directory contains the Markdown-first source for **Evaluating the Impact of Compute–Storage Separation on Retrieval Systems**.

## Source of truth

`thesis.md` was exported from the thesis Google Doc and normalized for Pandoc/LaTeX. Manual numeric references were replaced with Pandoc citation keys backed by `references.bib`. The Google Docs TOC/List-of-Figures/List-of-Tables placeholders were intentionally removed because they will be generated by the final LaTeX build.

The seven current benchmark figures are stored under `figures/`. They are PNG exports from the review document; the final formatting pass should replace them with vector PDF/SVG outputs generated directly from the benchmark analysis where possible.

## Build direction

The intended final pipeline is:

```text
thesis.md + references.bib + metadata.yaml
              |
            Pandoc
              |
          XeLaTeX/PDF
```

The final template should enforce CODE's 12 pt proportional font, 1.5 body spacing, approximately 3 cm left / 3.5 cm right margins, Roman-numbered front matter, Arabic-numbered main matter, table captions above tables, and figure captions below figures.

## Privacy

Street address, email address, and student ID from the Google Docs title page are intentionally not included in repository metadata. If those fields are required on the submission title page, keep them in a private/local metadata file rather than committing them to a public repository.

## Citation notes

The bibliography intentionally omits uncited draft references. Online documentation entries include access dates. Results and discussion of the benchmark's own measurements are not externally cited unless they make a separate architectural claim.
